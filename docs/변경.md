```python
return {"status": "retrain_triggered"}   # (재학습 없음, 힌트는 주석으로만 존재)

from data.features import load_rows, SEQ_LEN

from serving_app.train_and_register import fine_tune

logger.info("[INFO] retrain triggered (window=last_21_days)")
```

## #3 `serving_app/monitoring/drift_detector.py` - `compute_rmse()` 구현

- **날짜:** 2026-09-30
- **구분:** TODO구현 (Day3 실습 4-1)
- **위치:** `serving_app/monitoring/drift_detector.py` `compute_rmse()`

**문제**
`compute_rmse()`가 `NotImplementedError`를 던져, 예측이 21건 쌓여 `is_drift()`가 판정을 시작하는 순간 오류 발생.

**변경**

```python
# 변경 전
raise NotImplementedError("compute_rmse를 구현하세요 (실습 4-1)")

# 변경 후  -  RMSE = sqrt( mean( (actual - predicted) ** 2 ) )
if not recent_predictions:
    return 0.0  # 빈 리스트는 드리프트 없음으로 간주
squared = [(p["actual"] - p["predicted"]) ** 2 for p in recent_predictions]
return (sum(squared) / len(squared)) ** 0.5
```

**사용법 / 확인**

```bash
python3 -c "
from serving_app.monitoring.drift_detector import compute_rmse, is_drift
assert compute_rmse([]) == 0.0
assert compute_rmse([{'predicted':100,'actual':103}]*21) == 3.0
assert not is_drift([{'predicted':100,'actual':103}]*21)   # 3.0 <= 4 -> 정상
assert is_drift([{'predicted':100,'actual':105}]*21)       # 5.0 >  4 -> 드리프트
assert not is_drift([{'predicted':100,'actual':200}]*20)   # 21건 미만 -> 판정 보류
print('ok')"
```
