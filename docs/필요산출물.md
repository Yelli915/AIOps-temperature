### 1-2. Lazy vs Eager 로딩 시간 비교표 ✅

- **산출물:** 모드별 서버 시작 시간 / 첫 `/predict` 응답 시간 표
- **근거:** `serving_app/model_loader.py` 상단 - "서버 시작 시간 / 첫 요청 응답 시간을 비교합니다. (44번 슬라이드 결과표 참고)"
- **얻는 방법:**
  1. Lazy 모드로 기동 → 첫 `/predict` 호출 → 서버 콘솔의 `[lazy] model loaded in X.XXXs on first request` 확인
     ```bash
     uvicorn serving_app.main:app --host 0.0.0.0 --port 8077
     curl -X POST localhost:8077/predict -H 'Content-Type: application/json' -d @req.json
     ```
  2. 서버 종료 후 Eager 모드로 기동 → 서버 콘솔의 `[eager] model loaded in X.XXXs at startup` 확인 → 첫 `/predict` 호출
     ```bash
     LOADING_MODE=eager uvicorn serving_app.main:app --host 0.0.0.0 --port 8077
     curl -X POST localhost:8077/predict -H 'Content-Type: application/json' -d @req.json
     ```
- **결과 기록:**

  | 모드 | 서버 시작 시간 | 첫 `/predict` 응답 시간 | 콘솔 로그 |
  |------|---------------|------------------------|-----------|
  | Lazy  | ( 0.53초 ) | ( 6.08초 ) | `[lazy] model loaded in 5.860s on first request` |
  | Eager | ( 4.45초 ) | ( 0.20초 ) | `[eager] model loaded in 3.918s at startup` |

  - 2026-10-01, `MODEL_SOURCE=local`(`v1-local`, `req.json` 응답 `predicted_temp: 21.13`). 서버 시작 시간 = 실행부터 `/health`가 응답할 때까지, 응답 시간 = `curl -w %{time_total}`
  - 두 번째 `/predict`는 두 모드 모두 약 0.03초 - 차이는 모델을 언제 로드하느냐(시작 vs 첫 요청)뿐
  - `/health`: Lazy 기동 직후 `model_loaded: false`, Eager 기동 직후 `true`

- **다른 확인 방법:** `curl localhost:8077/health`의 `model_loaded` - Lazy는 첫 요청 전 `false`, Eager는 기동 직후 `true`
- [x] Lazy / Eager 실행
- [x] 측정값 표에 기록
