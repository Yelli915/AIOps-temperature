서버실 센서 데이터 업로드

data/uploads/는 여기서 업로드한 CSV만 쌓이는 곳입니다. 학습(train_and_register.py 등)은 항상 가장 최근에 올라온 파일을 사용합니다. data/sample_server_room.csv를 예시로 올려보세요 (컬럼: Timestamp, Temp, LoadKW, 선택 Setpoint · 최소 720행).

드리프트 시뮬레이션

하루 주기 온도 곡선으로 정상/드리프트(설정온도 +3°C) 배치를 만들어 /predict/batch-test로 전송합니다. 배치는 직전 배치의 마지막 24시간에 이어 보내며, 서버는 이어진 배치를 재학습 데이터로 쌓습니다(192시간). 드리프트 배치를 여러 번 보내면 감지 → (데이터가 쌓이면) 재학습 → (게이트 통과 시) 재배포까지 진행됩니다.
